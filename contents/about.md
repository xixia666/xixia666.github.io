
**SKY·紫罗兰** 是一款 Android 悬浮球工具应用，使用 GLES3 + JNI 渲染 ImGui 界面，支持悬浮窗菜单、动态功能模块加载和远程热更新。

#### 核心特性

- **悬浮球菜单**：桌面悬浮球一键展开 ImGui 渲染的功能菜单
- **动态模块加载**：feature.so / ui.so 热更新，无需重装 APK
- **卡密验证**：内置 native 验证体系，支持设备绑定
- **安全防护**：注入检测、模拟器检测、网络代理检测
- **主题定制**：支持自定义主题色

#### 技术栈

- **语言**: C/C++ (JNI) / Java
- **渲染**: OpenGL ES 3.0 + ImGui
- **架构**: 悬浮窗 Service + GLSurfaceView + Native Bridge
- **最低版本**: Android 5.0 (API 21)
