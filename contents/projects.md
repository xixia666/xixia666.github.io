
#### grok2api

多账号 API 网关，支持 Grok Build、Grok Web 和 Grok Console。将多个限速账号聚合到单个 OpenAI 兼容端点，支持故障转移和轮换。

`python` `FastAPI` `openai-compat`

→ [查看源码](https://github.com/xixia666/grok2api)

#### Zygisk-Il2CppDumper

使用 Zygisk 在运行时转储 il2cpp 元数据。在混淆生效之前挂钩加载器，从受保护的 Unity 游戏中恢复类型/方法/字段名称。

`c++` `zygisk` `il2cpp` `android`

→ [查看源码](https://github.com/xixia666/Zygisk-Il2CppDumper)
